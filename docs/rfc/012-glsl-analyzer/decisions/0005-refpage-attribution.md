# 0005 — Khronos reference-page prose is OPL v1.0; attribution lives in three places

**Status:** Accepted (Phase 1, P1-10). Closes open question **q4**.

## Decision

The builtin documentation embedded in `glsl-spec` is Khronos Group reference-page
material under the **Open Publication License v1.0**, and we carry that attribution in
three places, all of which ship or are reviewed:

1. **The header of every generated file** in `crates/wgsl-shader/glsl-spec/src/generated/`
   — copyright holder, licence name, licence URL, the docs.gl commit the pages came from,
   and a statement that the prose was modified. Written by `glsl-spec-gen`, so it cannot
   drift from the tables it describes.
2. **[extensions/wgsl-shader/THIRD-PARTY-NOTICES.md](../../../../extensions/wgsl-shader/THIRD-PARTY-NOTICES.md)**
   — because the VSIX ships a wasm binary with that prose compiled into it, and a user who
   asks what is inside the extension deserves an answer that is not a source-tree comment.
3. **This record**, as the reasoning.

No docs.gl page is committed to this repository — not as data, not as a test fixture.
This closes the footnote in [tasks/phase-1-spec-pipeline.md](../tasks/phase-1-spec-pipeline.md):
generator tests read `temp/docs.gl` in place and skip when it is absent, exactly as
[decision 0004](0004-corpus-in-place.md) has corpus tests read `temp/glslang/Test/`. The
pure tests (markdown conversion, label parsing) use fixtures written by hand for the test.

## What the licence actually is

Two layers, and they are not the same licence.

**The docs.gl scaffolding** — the repository's own build scripts, CSS, templates and the
reshaping of the pages into uniform XHTML. `temp/docs.gl/readme.md`, first line:

> docs.gl is a public domain web scaffolding for the OpenGL documentation.

The repository carries no `LICENSE` file; that sentence is the whole statement. Public
domain, nothing owed.

**The reference-page prose** — the descriptions, parameter notes and version tables, which
are Khronos's, republished. Every one of the 314 pages we read ends with a `Copyright`
section, in three variants that differ only in the year (309 say 2011-2014, four say 2014,
one says 2012-2014):

> Copyright © 2011-2014 Khronos Group. This material may be distributed subject to the
> terms and conditions set forth in the Open Publication License, v 1.0, 8 June 1999.
> <https://opencontent.org/openpub/>

So: OPL v1.0, verbatim from the source we read, with no ambiguity to resolve.

## Why this satisfies it

OPL v1.0 permits redistribution and modification. Its licence options — VI(A), which
forbids substantively modified versions, and VI(B), which forbids commercial book form —
apply *only when the copyright holder invokes them on the work's cover*. Khronos's notice
invokes neither, so neither binds us. What does bind us, and how each is met:

| OPL requirement | How the generated tables meet it |
| --- | --- |
| Retain the copyright notice | `Copyright (c) 2011-2014 Khronos Group` in every generated file's header |
| Reference the licence and its location | Named, with `https://opencontent.org/openpub/`, in the same header |
| Mark modified versions as modified, and say what changed | The header states the prose was converted to markdown, capped per entry, and had formulas and tables dropped |
| Identify the original and where to find it | docs.gl's URL and the exact commit hash, plus the `sl4/`/`el3/` directories |

The transformation itself is the one described in
[design/spec-pipeline.md](../design/spec-pipeline.md): XHTML → markdown, boilerplate
stripped, MathML and tables replaced by a "see the reference page" note, each entry capped
at 1.2 KB. It is an abridgement, not a rewrite, which is precisely the case the "modified
versions" clause exists for.

The version tables are facts about the language rather than expression, and the prototypes
are the language's own syntax; neither is a copyright question. Only the prose is, and only
the prose is attributed.

## Consequences

- **The attribution is generated, not maintained.** Anyone editing the header edits
  `emit::header` in `glsl-spec-gen`, and the determinism test fails if the committed files
  disagree — so the notice cannot rot while the tables move on.
- **`extensions/wgsl-shader/THIRD-PARTY-NOTICES.md` is new** and, unlike the
  `fast-element-ultra` and `typst-ultra` notices, is hand-written: it covers embedded
  *documentation*, which no `cargo about` run knows about. When Phase 6 adds a generated
  Rust-dependency notice for this extension, the Khronos section stays hand-written above
  it.

  **P6-03 outcome.** It does, with one refinement: the hand-written prose moved *into*
  `crates/wgsl-shader/wgsl-lsp-wasm/about.hbs`, above the cargo-about sections, so the
  whole file is generated by `pnpm run licenses` and carries a single "do not edit"
  header. Two sources of truth in one file would have been an invitation to edit the
  half a regeneration then overwrites.
- **The OPL is not an OSI licence**, and the prose is therefore not under the MIT terms the
  crates carry. The distinction is stated in the notice file so nobody assumes otherwise.
- **A docs.gl update is a licence checkpoint**, cheap because it is one grep: if a future
  checkout's `Copyright` sections stop saying OPL v1.0, the generator's header is wrong and
  this record needs revisiting. `research/docs-gl.md` §10 records how the check was made.
