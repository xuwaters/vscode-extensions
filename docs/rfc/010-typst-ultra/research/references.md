## 2. Fonts — and the one that needs care

The extension ships typst's default font set (~9.5 MB) as VSIX assets
([proposal.md §6.3](../proposal.md#63-fonts-ship-as-vsix-assets-not-inside-the-wasm)). These are the files
from `typst-assets` 0.15.1 `files/fonts/`, and they are **not** all under one license. From
[`typst-assets` `NOTICE`](https://github.com/typst/typst-assets/blob/main/NOTICE):

| Files | License |
| --- | --- |
| `LibertinusSerif-*.otf` (6 files) | **SIL Open Font License 1.1** — © 2012-2024 The Libertinus Project Authors, RFN "Linux Libertine", "Biolinum", "STIX Fonts" |
| `NewCM*.otf` **except** `NewCM10-Regular.otf` (6 files) | **GUST Font License 1.0** |
| `NewCM10-Regular.otf` | ⚠️ **GPL-3.0-or-later + Font Exception (FE) + Distribution Exception (DE)** |
| `DejaVuSansMono*.ttf` (4 files) | **Bitstream Vera Fonts License**; DejaVu changes are public domain; Arev glyphs © Tavmjong Bah |
| `Foxit*.pfb` (13 files) | **BSD-3-Clause** — © 2014 PDFium Authors (the PDF base-14 substitutes used by PDF export) |

### The `NewCM10-Regular.otf` question

This one file is GPL-3.0-or-later. The **Font Exception** means documents that embed the font do not become
GPL, and the **Distribution Exception** permits distributing it alongside other software. typst itself, and
every typst distribution, ships it on exactly this basis.

Three things follow, and they should be settled before Phase 1 ships rather than after:

1. Our `LICENSE.md` must reproduce the SIL OFL 1.1, GUST 1.0, Bitstream Vera, BSD-3-Clause, and
   GPL-3.0+FE+DE texts, each scoped to the files it covers. Nothing here permits summarizing.
2. The bundled fonts must live in a clearly-labelled directory (`assets/fonts/`) with a `README` pointing
   at `LICENSE.md`, so the boundary between our code and redistributed fonts is unambiguous.
3. If shipping a GPL font is judged undesirable regardless of the exceptions, the fallback is to drop
   `NewCM10-Regular.otf` and let typst's font fallback handle it — at the cost of documents rendering
   differently from `typst compile`. This is a variant of
   [0004](../decisions/0004-bundle-default-fonts.md) and is called out here because it is a licensing
   decision, not a size one.

## 5. What goes in `extensions/typst-ultra/LICENSE.md`

Following the repo's existing format ([markdown-preview-ultra/LICENSE.md](../../../../extensions/markdown-preview-ultra/LICENSE.md)):
`NO LICENSE` for our own code, then a Third-Party Notices section covering everything the **published
package** redistributes.

```markdown
NO LICENSE

---

# Third-Party Notices

This extension's published package (`dist/`, `wasm/`, `assets/`) contains third-party
software redistributed under the licenses below. Each copyright holder retains their
rights; nothing here grants any license to this extension itself.

## The Typst compiler

`wasm/typst_lsp_wasm_bg.wasm` statically links the Typst compiler and its IDE support
(<https://github.com/typst/typst>, version 0.15.1), redistributed under the Apache
License 2.0:

> Copyright 2019 The Typst Project Developers

[full Apache-2.0 text]

## typstyle

The same WASM module links typstyle (<https://github.com/typstyle-rs/typstyle>,
`typstyle-core` 0.15.1), redistributed under the Apache License 2.0.

## Fonts

The font files shipped at `assets/fonts/` come from typst-assets
(<https://github.com/typst/typst-assets>) and are redistributed under the licenses
below, per file group:

- `LibertinusSerif-*.otf` — SIL Open Font License 1.1 [full text]
- `NewCM*.otf` except `NewCM10-Regular.otf` — GUST Font License 1.0 [full text]
- `NewCM10-Regular.otf` — GPL-3.0-or-later with Font Exception and Distribution
  Exception [full text]
- `DejaVuSansMono*.ttf` — Bitstream Vera Fonts License [full text]
- `Foxit*.pfb` — BSD-3-Clause, Copyright 2014 PDFium Authors [full text]

## Other Rust dependencies

[Apache-2.0 / MIT texts for the transitive crate graph, generated by cargo-about]

## Acknowledgement

The architecture of this extension was informed by tinymist
(<https://github.com/Myriad-Dreamin/tinymist>, Apache-2.0), whose WASM language-server
build demonstrated the approach. No tinymist code is included in this extension.
```

The transitive Rust dependency notices should be **generated**, not hand-maintained —
[`cargo-about`](https://github.com/EmbarkStudios/cargo-about) run as part of `package`, with its output
committed so a diff is reviewable. A 304-crate dependency graph is not something to track by hand.
