# Phase 1 — Foundation

**Goal**: the whole architecture running end to end, carrying exactly one feature.
**Exit criterion**: open a `.typ` file, see typst's real errors and warnings inline, as you type.
**Status**: ☑ Complete — 16 / 16

Phase 1 deliberately ships one LSP feature. Diagnostics require the compile session, the VFS, fonts, the
WASM boundary, the child process, and span mapping — so if diagnostics work, the architecture works.
Everything in Phase 2 is then additive.

**P1-14 notes.** `wasm-opt` needed more than the RFC specified: current rustc emits bulk-memory,
sign-extension, and non-trapping float-to-int instructions for `wasm32-unknown-unknown` by default, and
wasm-opt refuses to validate a module using features it has not been told about. The recorded flag list is
`["-Os", "--strip-debug", "--enable-bulk-memory", "--enable-bulk-memory-opt",
"--enable-nontrapping-float-to-int", "--enable-sign-ext", "--enable-mutable-globals",
"--enable-reference-types", "--enable-multivalue"]`; without them the build fails with
*"memory.fill operations require bulk memory"*. This was the repo's **first CI workflow** —
[`.github/workflows/ci.yml`](../../../../.github/workflows/ci.yml) — so it also runs `cargo test` and
`pnpm test`. Its clippy step is scoped to the four typst crates, because several older crates in the
workspace carry pre-existing warnings this RFC has no business editing.

**P1-15 notes.** `cargo-about` generates
[`THIRD-PARTY-NOTICES.md`](../../../../extensions/typst-ultra/THIRD-PARTY-NOTICES.md) (296 crates:
212 Apache-2.0, 52 MIT, 26 Unicode-3.0, and a handful of others), regenerated by `pnpm run licenses`.
[`LICENSE.md`](../../../../extensions/typst-ultra/LICENSE.md) carries the compiler, typstyle, and font
notices by hand, with §4 copied verbatim from typst-assets' own `NOTICE` — including the Foxit
(BSD-3-Clause), ICC profile (CC0), and ICU data notices, which the RFC's plan missed because those are
embedded in the WASM rather than shipped as files.

**P1-03 notes.** A **fourth port** was needed and added: `ClockProvider`. `World::today` needs a clock, and
`SystemTime::now()` traps on `wasm32-unknown-unknown` — the host reads `Date.now()` and its timezone
offset and passes both across. The fs implementations live in `typst-session::fs` behind a default-on
`fs-ports` feature rather than in `tests/`, so `typst-lsp-core`'s tests can use them too; the WASM crate
turns the feature off, keeping `std::fs` out of the artifact.

**P1-16 notes.** An error inside an imported file is attributed to that file with the `#import` chain as
related information — confirmed by
[`compile__an_error_in_an_imported_file_is_attributed_to_that_file.snap`](../../../../crates/typst/typst-session/tests/snapshots/).
Fan-out cost was not separately expensive: the multi-file fixture compiles in the same order of time as a
single-file one, because the cost is the content, not the file count.

**P1-07 notes.** The property test caught a real bug: clamping an out-of-range `character` to
`line_to_range().end` lands *past* the newline, i.e. on the next line. The fix trims the line terminator
before clamping. `Server` is generic over a single [`Ports`] bundle rather than four type parameters,
which keeps every signature in the crate to one bound.

**P1-09 notes.** The whole crate is `#[cfg(target_arch = "wasm32")]`-gated except the path-key encoding, so
`cargo test` passes with no WASM toolchain while `SingleThreaded`'s `compile_error!` still fires for any
*threaded* WASM target.

**P1-11 — research debt closed.** Indexing the 17 bundled fonts (9.2 MB) costs **10 ms cold** and **<1 ms**
from the on-disk cache, measured by
[`server/fonts.test.ts`](../../../../extensions/typst-ultra/server/fonts.test.ts) and logged at every
startup. That is 2.5% of the 400 ms server-start budget, so the target is not at risk from fonts — the
spike's worry that font parsing might dominate cold start does not hold. The host callback is `now()`
rather than the RFC's `today(offsetMinutes)`, because a `Datetime` at an arbitrary offset is cleaner to
compute in Rust than to marshal.

## Definition of done

- [x] `pnpm run package` produces a VSIX containing `wasm/`, `assets/fonts/`, and `dist/` — 31 files, 16 MB
- [x] Opening a `.typ` starts the server lazily; opening a non-typst file does not
- [x] Errors and warnings appear as you type, and **clear** when fixed
- [x] An error in an imported file appears in the Problems panel under that file's URI
- [x] Deleting `wasm/` produces a friendly status-bar message, not a stack trace
- [x] `cargo test` passes without a WASM toolchain present
- [x] CI builds `wasm32-unknown-unknown`

One correction to the plan: the shared `.vscodeignore` template had no entry for a `server/` directory,
because no extension had ever had one — the first VSIX shipped the server's TypeScript source. Fixed in
`scripts/templates/.vscodeignore` and re-synced across all 19 extensions, per the template's own rule.
