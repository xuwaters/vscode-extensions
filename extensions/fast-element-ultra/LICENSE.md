## 4. MDN Web Docs

Many of the element and attribute descriptions shown on hover and in
completion are text written for [MDN Web Docs](https://developer.mozilla.org/)
by Mozilla contributors:

- the HTML descriptions arrive through `@vscode/web-custom-data` (§3), whose
  own README says its MDN-derived content is distributed under CC BY-SA 2.5;
- the SVG and MathML entries in the same table (`generator/svg-data.json` in
  `crates/fast/fast-html-data`) were curated for this repository from MDN's SVG
  and MathML references;
- the CSS property descriptions inside `vscode-css-languageservice` (§1) are,
  per that package's README, likewise built on MDN content.
